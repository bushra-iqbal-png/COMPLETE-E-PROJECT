# 🎁 Prestige Gift Shop — E-Commerce Website Project

A multi-page gift shop website project focused on presenting customized gift ideas for birthdays, anniversaries, weddings, and other special occasions.

## 📌 Project Overview

Prestige Gift Shop is a front-end web development project created to organize gift categories and provide visitors with information about the shop, its policies, and contact options.

The project includes multiple HTML pages, CSS stylesheets, JavaScript files, and supporting assets.

## ✨ Key Pages

- **Home:** Main landing page for the gift shop.
- **Birthday Gifts:** Presents birthday gift ideas.
- **Anniversary Gifts:** Showcases anniversary gift ideas.
- **Wedding Gifts:** Presents wedding gift options.
- **About Us:** Introduces the gift shop.
- **Contact Us:** Provides contact information.
- **FAQs:** Organizes frequently asked questions.
- **Complaint:** Provides a complaint-related page.
- **Shipping Policy:** Presents shipping information.
- **Returns:** Presents return-related information.
- **Terms and Conditions:** Provides the terms page.

## 🛠️ Technologies Used

- HTML5 — Page structure and content
- CSS3 — Website styling and layout
- JavaScript — Client-side interactions

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Navigate through the available pages using the website's links.

A web server may be needed if the project uses features that require one. This repository's front-end pages can be explored locally in a browser.
